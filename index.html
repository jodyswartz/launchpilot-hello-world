Hello from LaunchPilot

Telegram-controlled AI coding agent.

How it works

  1. TG

    Telegram idea

    Send a product idea, bug, or change request straight from Telegram.

  2. </>

    Codex build

    Codex reads the repo, makes the change, and verifies the work.

  3. PR

    GitHub PR

    LaunchPilot opens a GitHub pull request ready for review.

  4. OK

    Approve and merge

    Review the diff, approve it, and merge when the update looks right.

  5. GO

    Open website

    Visit the updated site and see the merged change live.
